# "Vitrine soutien scolaire" My Brochure Site to advertise my private lessons

The latest render of the code is available [here](https://clement-guillaumin.github.io/vitrine-soutien-scolaire/)

## For devs : How to ...

### ... Run Locally

```bash
npm install
npm run dev
```

Should give you a localhost link to look at the ongoing project.

### ... Deploy to the public branch (GitHub Pages)

```bash
npm run deploy
```

Publishes the build to the `gh-pages` branch.
